1. **Can I order the values?**
2. **Can I do meaningful arithmetic on them?**

That gives the four levels of measurement.

|Level|Ordered?|Add/Subtract?|Multiply/Divide?|Example|
|---|---|---|---|---|
|**Nominal**|❌|❌|❌|Blood type, Student ID|
|**Ordinal**|✅|❌|❌|Rankings, T-shirt sizes|
|**Interval**|✅|✅|❌|Celsius, Calendar year|
|**Ratio**|✅|✅|✅|Height, Weight, Salary, Storage|

---

## 1. Nominal (Just names)

Think **labels**.

Examples:

- Blood type: A, B, AB, O
    
- Student ID: 1001, 1002
    
- Gender
    
- City
    

You cannot say

- ❌ 1002 > 1001 academically
    
- ❌ Average student ID
    
- ❌ Difference between IDs
    

Only things like

- Count frequency
    
- Find the most common category (Mode)
    

### Quiz example

> Student ID numbers

Answer:

> **Nominal**

---

## 2. Ordinal (Order exists)

There is an order.

Examples

Small < Medium < Large < XL

1st > 2nd > 3rd

Poor < Average < Good < Excellent

But you **don't know how much bigger** one is than another.

Example

```
S M L XL
```

Is Medium exactly halfway between Small and Large?

No.

So assigning

```
S=1
M=2
L=3
XL=4
```

doesn't suddenly make arithmetic valid.

### Quiz example

Average size = 2.5

Meaning?

Nothing.

Hence

> **Ordinal**

---

## 3. Interval (Equal spacing)

Here,

Differences matter.

Example

```
10°C
20°C
30°C
```

Difference

20−10 = 10

30−20 = 10

These differences are meaningful.

BUT

0°C is **not** "no temperature."

Therefore

40°C is **not twice** 20°C.

This is the single most important fact.

### Examples

- Celsius
    
- Fahrenheit
    
- Calendar year
    

---

### Quiz example

Why is Celsius interval?

Because

> **0°C is arbitrary.**

---

## 4. Ratio (True zero)

Same as interval

PLUS

Zero actually means **none**.

Examples

Weight

```
0 kg
```

means no weight.

Salary

```
$0
```

means no salary.

Storage

```
0 GB
```

means no storage.

Distance

```
0 km
```

means no distance.

Now ratios make sense.

```
100 GB
```

is exactly twice

```
50 GB
```

---

### Quiz example

Monthly salary

Answer

> **Ratio**

## Your quiz questions in one line

- Blood type → **Nominal**
    
- Student ID → **Nominal**
    
- T-shirt size → **Ordinal**
    
- Class rank → **Ordinal**
    
- Celsius → **Interval**
    
- Year of birth → **Interval**
    
- Salary → **Ratio**
    
- Height → **Ratio**
    
- Weight → **Ratio**
    
- Storage (GB) → **Ratio**
    

One caution about that last storage question: by the standard statistical definitions used in textbooks, **storage in GB is a ratio-scale variable**, because 0 GB is a true zero and statements like "100 GB is twice 50 GB" are meaningful. If your quiz marked that wrong, it's likely due to an error or ambiguity in the quiz rather than the underlying concept.
