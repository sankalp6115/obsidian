Telecommunication framework allows digital devices to interact via wired/wireless medium to share resources (hardware or software).
Network is set of nodes connected by communication links.

**Data communication requires these:**
- Sender
- Receiver
- Medium 
- Message
- Protocols

**Nodes** - End device or Intermediary devices
	**End Node** - Beginning or End of networking activity.
	eg. Computer, PC, Laptop, VoIP etc
	**Intermediary Node** - Forward data from one node to other.
	eg. Switch, Bridge, Hub, Repeater, Cell Tower, Firewall, Router, WirelessAP etc

**Media** - Medium representing way of transport of data. Can be wired or guided and wireless or unguided.
eg. Wired - Ethernet, Fibre=optic cable, Coaxial Cable, USB
Wireless - IR,  Wifi, Radio, Microwaves, Satellite

**Services** - Mail, VoIP, Storage, Messaging etc

### Characteristics
**Effectiveness**
- Delivery - correct destination
- Accuracy - delivered accurately without errors
- Timeliness - delivered within time
- Jitter - uneven delay

**Reliability** 
Less frequent failures and Less time to resolve failure.

**Performance** 
Response time, transit time, number of user.

**Security**
CIA Triad 
	- CIA -> Confidentiality, Integrity, Availability
Ability to prevent unauthorized access, misuse and forgery. 
Ability to provide confidentiality,, integrity and availability.

**Fault Tolerance**
Ability to continue working despite failures and ensure no loss of service.

**Scalability**
Ability to grow based on need and have good performance even on growth.

**Quality of Service (QoS)**
Ability to set priorities and manage data traffic to reduce data loss and latency.

### Transmission Modes
- Simplex - Unidirectional communication, one devices sends then other only receives.
	- eg. TV, Radio etc
	- One-way road with one lane
- Half-duplex - Bidirectional communication, but only one operation at a time. One device sends,, other receives.
	- eg. Walkie-Talkie etc
	- Both way road with one lane
- Full-duplex - Bidirectional communication, both sending and receiving can take place at the same time.
	- eg. Telephone
	- Both way road multi-lane

### Protocols
Set of rules governing data communication.

Human communication requires -> 
- Sender and Receiver
- Common language and grammer
- Speed and Timing of delivery
- Confirmation and ACK requirements

In networking, 
- Message encoding 
	- Source -> Encoder -> Transmitter -> Receiver -> Decoder -> Message Destination
- Message format and encapsulation
	- Encapsulate info to identify sender and receiver rightly
- Message timing
	- Long message broken into smaller pieces to travel across network.
- Message size
- Message delivery options
